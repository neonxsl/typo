# typo

> a minimalist, keyboard only typing test with a xp and leveling up system, as well as cloud sync and leaderboards. no mouse allowed! #tabbed

live at https://typo.neonxsl.dev

## features:
- keyboard only! the navigation is 100% keyboard only. (so u actually gotta use ur kb)
- epic graphs showing your dynamic typing speed: chart.js for clean data visualisation
- 6 languages and 3 coding languages: with dynamic font switching from space grotesk to space mono!
- xp/leveling system: harder gamemodes such as longer or coding provide multipliers for xp, and a full on leveling system
- streak system: come back everyday to grow your streak!
- leaderboard; compete against others, challenge your friends, you can see overall rankings as well as top wpm rankings per gamemode
- cloud syncing and auth: login with github and sync directly to appwrite, ensuring your data stays across all your devices.
- minimal design: cleaaan typography and no bloat whatsoever, very lightweight as well!
